# Subscriptr

iOS subscription tracker app.

## Tech Stack
- UI: SwiftUI
- Persistence: SwiftData
- Min deployment: iOS 17

## Architecture
- Views/ — SwiftUI screens
- ViewModels/ — ObservableObject logic
- Models/ — Subscription, Card, Category
- Services/ — Data persistence

## Design
- Accent color: #2563EB (blue)
- Clean, minimal aesthetic
- 4 tabs: Dashboard, Subs, Analytics, Profile
